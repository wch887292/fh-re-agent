# RE-Agent

## 一、项目简介

RE-Agent 是教育营销内容合规生成与审核 Agent 平台，聚焦 AI 训练数据的生产与管理，面向教育营销内容场景，覆盖从原始素材到可用训练数据的全链路。平台由四个核心模块构成：

- 数据集工程：负责数据集的构建、管理、版本化与发布，支持数据来源标注、生命周期状态管理（构建中、已冻结、已发布、已下线）以及样本总量的统计与导出；
- 标注：针对数据集内的样本逐条进行标注，记录输入内容、期望输出与业务标签，形成可被下游模型训练直接消费的结构化标注数据，并支持按数据集与状态进行筛选；
- 审核流：对标注与数据集两类对象进行多级审核，审核结果分为待审核、通过、驳回三档，提供审核人、意见留痕与结果追溯，保障训练数据的质量与合规底线；
- 看板：以统一看板视图集中呈现数据集、标注、审核三大维度的数量、状态分布与处理进度，辅助团队进行进度判断、瓶颈定位与质量抽检。

四个模块前后衔接、协同工作，构成 AI 训练数据从生产、清洗、质检到管理的完整闭环，让教育营销内容的安全合规生成建立在可靠的训练数据之上。

## 二、技术栈

- 前端：React 加 Vite
- 后端：Node.js 加 Express 加 TypeScript
- 数据库：SQLite

## 三、本地启动

启动后端服务：进入 `apps/server` 目录，在 cmd 中执行命令 `npx tsx src/index.ts`，后端默认监听 8802 端口。

启动前端服务：进入 `apps/web` 目录，在 cmd 中执行命令 `npx vite --port 5174`，前端默认监听 5174 端口。
